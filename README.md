# My Portfolio Website

Welcome to my personal portfolio website! This website showcases my work, projects, skills
## Features

- **About Me**: A brief introduction to who I am, my background, and my career journey.
- **Projects**: A collection of my personal and professional projects, including code samples, live demos, and descriptions.
- **Skills**: An overview of the programming languages, tools, and technologies I am proficient in.
- **Contact**: A section where you can get in touch with me for any inquiries, opportunities, or collaborations.

## Technologies Used

This portfolio website is built using the following technologies:

- **HTML**: For the structure and layout of the website.
- **CSS**: For styling the website and ensuring a responsive design.
